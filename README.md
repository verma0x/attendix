# 📚 Attendix

> A simple and modern attendance tracker for students.

Attendix lets you mark daily attendance directly from a calendar. Select a date, choose **Present** or **Absent**, and the attendance percentage is calculated automatically.

## ✨ Features

- 📅 Interactive monthly calendar
- 🟢 Mark dates as Present
- 🔴 Mark dates as Absent
- 📊 Automatic attendance percentage
- 📈 Visual attendance progress bar
- ⚠️ Attendance status indicator
- 💾 Browser LocalStorage
- 📱 Responsive design
- 🔄 Previous, next and current month navigation
- ♻️ Reset attendance data

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## 💻 How To Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/attendix.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

No installation or dependencies are required.

## 📊 Attendance Calculation

```text
Attendance % = (Present Classes / Total Classes) × 100
```

- 🟢 75% or above — Safe
- 🟡 60%–74% — Needs attention
- 🔴 Below 60% — Low
